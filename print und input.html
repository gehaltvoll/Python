print und input

Mit print() gibt ein Programm etwas aus, mit input() fragt es nach. Zusammen machen die beiden aus einem Programm ein Gespräch. Unten können Sie alles mit echtem Python im Browser ausprobieren.

1 · Ausgabe

print(): etwas anzeigen

print() schreibt das, was in den Klammern steht, in die Konsole. Danach beginnt automatisch eine neue Zeile.

# Text steht immer in Anführungszeichen
print("Guten Morgen!")
print('Einfache Anführungszeichen gehen auch.')

# Zahlen und Rechnungen ohne Anführungszeichen
print(42)
print(7 * 6)

# Mit Anführungszeichen ist es Text – es wird nicht gerechnet
print("7 * 6")
Guten Morgen! Einfache Anführungszeichen gehen auch. 42 42 7 * 6

Mehrere Werte mit Komma

Trennen Sie mehrere Werte mit Kommas. print() setzt dann automatisch ein Leerzeichen dazwischen. So lassen sich Text und Zahlen problemlos mischen.

punkte = 18
print("Sie haben", punkte, "Punkte erreicht.")
print("Doppelt so viele wären", punkte * 2)
print()          # leere Zeile
print("Ende")
Sie haben 18 Punkte erreicht. Doppelt so viele wären 36 Ende
Merke

Was in Anführungszeichen steht, gibt Python genau so aus. Was ohne Anführungszeichen steht, rechnet Python zuerst aus oder ersetzt es durch den Wert der Variable.

2 · Texte verbinden

Mit + zusammensetzen und str()

Statt mit Kommas können Sie Texte auch mit + aneinanderhängen. Man nennt das Verketten. Dabei setzt Python kein Leerzeichen ein – das müssen Sie selbst in die Anführungszeichen schreiben.

vorname = "Lea"
nachname = "Meier"
print(vorname + nachname)
print(vorname + " " + nachname)
print("Hallo " + vorname + "!")
LeaMeier Lea Meier Hallo Lea!

Text und Zahl: str() hilft

Eine Zahl lässt sich nicht direkt mit Text verketten. Python weiss nicht, ob es rechnen oder Text anhängen soll, und meldet einen Fehler. Mit str() verwandeln Sie die Zahl zuerst in Text.

alter = 16
# print("Ich bin " + alter + " Jahre alt.")   → TypeError
print("Ich bin " + str(alter) + " Jahre alt.")
print("Nächstes Jahr: " + str(alter + 1))
Ich bin 16 Jahre alt. Nächstes Jahr: 17

3 · Eingabe

input(): nachfragen und speichern

input() zeigt den Text in den Klammern an, die sogenannte Eingabeaufforderung, und wartet dann, bis jemand etwas eintippt und Enter drückt. Das Eingetippte gibt input() zurück. Damit es nicht verloren geht, speichern Sie es in einer Variable.

stadt = input("Wo wohnen Sie? ")
print("Schön, ich war auch schon in", stadt)
Wo wohnen Sie? Bülach Schön, ich war auch schon in Bülach

Schreiben Sie am Ende der Eingabeaufforderung ein Leerzeichen, also "Wo wohnen Sie? ". Sonst klebt die Eingabe direkt am Fragezeichen.

Wichtig: input() liefert immer Text

Auch wenn jemand 5 eintippt, speichert Python den Text "5". Mit Text kann man nicht rechnen: "5" + "3" ergibt "53".

4 · Umwandeln

int() und float(): aus Text wird eine Zahl

Um mit einer Eingabe zu rechnen, wandeln Sie sie um: int() für ganze Zahlen, float() für Kommazahlen.

✗ Ohne Umwandlung

a = input("Zahl 1: ")
b = input("Zahl 2: ")
print(a + b)
Zahl 1: 5 Zahl 2: 3 53

✓ Mit int()

a = int(input("Zahl 1: "))
b = int(input("Zahl 2: "))
print(a + b)
Zahl 1: 5 Zahl 2: 3 8

int(input(...)) liest man von innen nach aussen: Zuerst fragt input() nach dem Text, dann macht int() daraus eine Zahl.

Kommazahlen mit float()

preis = float(input("Preis in CHF: "))
anzahl = int(input("Anzahl: "))
total = preis * anzahl
print("Total:", total, "CHF")
print("Total: " + str(total) + " CHF")

Die häufigsten Fehler

  • Anführungszeichen vergessenprint(Hallo) sucht eine Variable namens Hallo und meldet NameError. Richtig: print("Hallo").
  • Text und Zahl mit + verbinden"Alter: " + 16 ergibt TypeError. Lösung: str(16) oder ein Komma in print().
  • Mit der Eingabe rechnen, ohne umzuwandelnAus "5" + "3" wird "53". Lösung: int(input(...)).
  • Komma statt Punkt bei Dezimalzahlenfloat("2,5") ergibt ValueError. In Python schreibt man 2.5.
  • Klammer vergessenBei int(input("Zahl: ") fehlt die letzte Klammer. Zählen Sie: Jede geöffnete Klammer braucht eine schliessende.

Übung 2 · Begrüssung

Schreiben Sie ein Programm, das nach Vor- und Nachnamen fragt und dann Willkommen, Lea Meier! ausgibt – einmal mit Kommas, einmal mit +.

Lösung anzeigen
vorname = input("Vorname: ")
nachname = input("Nachname: ")
print("Willkommen,", vorname, nachname + "!")
print("Willkommen, " + vorname + " " + nachname + "!")

Beim Ausrufezeichen hilft +, sonst stünde ein Leerzeichen davor.

Übung 3 · Geburtsjahr

Das Programm fragt nach dem Alter und gibt aus: Sie sind etwa im Jahr 2010 geboren. Verwenden Sie das aktuelle Jahr 2026.

Lösung anzeigen
alter = int(input("Wie alt sind Sie? "))
jahr = 2026 - alter
print("Sie sind etwa im Jahr " + str(jahr) + " geboren.")

Ohne int() könnte Python 2026 - "16" nicht berechnen.

Übung 4 · Fehler finden

Dieses Programm soll den Durchschnitt zweier Noten berechnen, hat aber drei Fehler. Finden und korrigieren Sie sie.

note1 = input("Note 1: ")
note2 = input("Note 2: ")
schnitt = (note1 + note2) / 2
print("Ihr Schnitt ist " + schnitt)
Lösung anzeigen
note1 = float(input("Note 1: "))
note2 = float(input("Note 2: "))
schnitt = (note1 + note2) / 2
print("Ihr Schnitt ist " + str(schnitt))

Noten können Kommazahlen sein, deshalb float() für beide Eingaben. Beim Verketten braucht schnitt ein str().
