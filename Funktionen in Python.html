# Teil 1

Warum Funktionen sinnvoll sind

Stellen Sie sich vor, Ihr Programm soll an mehreren Stellen denselben Willkommensrahmen ausgeben. Ohne Funktionen kopieren Sie die gleichen Zeilen immer wieder. Das funktioniert, wird aber schnell unübersichtlich. Und wenn Sie den Rahmen später ändern möchten, müssen Sie jede Kopie einzeln anpassen und hoffen, dass Sie keine vergessen.

Eine Funktion löst dieses Problem. Sie schreiben den Code einmal, geben ihm einen Namen und rufen ihn danach über diesen Namen auf, so oft Sie wollen.

Weniger Wiederholung

Code, den Sie mehrmals brauchen, steht nur an einer Stelle.

Einfacher ändern

Eine Korrektur in der Funktion wirkt sofort bei jedem Aufruf.

Bessere Übersicht

Ein guter Name wie willkommen() sagt, was passiert, ohne dass man den Code lesen muss.

Probleme zerlegen

Eine grosse Aufgabe lässt sich in kleine Funktionen aufteilen, die man einzeln testen kann.

Sie kennen schon Funktionen

print(), input(), len() und int() sind Funktionen, die Python mitbringt. Mit def schreiben Sie nun Ihre eigenen.

# Teil 2

Funktionen ohne Parameter

Eine Funktion entsteht in zwei Schritten. Zuerst definieren Sie sie mit def: Sie legen fest, wie sie heisst und was sie tut. Danach rufen Sie sie auf, indem Sie ihren Namen mit runden Klammern schreiben. Erst beim Aufruf wird der Code in der Funktion tatsächlich ausgeführt.

def trennlinie():
    print("----------")

trennlinie()
1

def (von «define», festlegen), dann der Name, leere Klammern und ein Doppelpunkt. Für den Namen gelten dieselben Regeln wie bei Variablen.

2

Der Funktionskörper ist eingerückt, wie bei if. Alles Eingerückte gehört zur Funktion.

3

Der Aufruf: Name mit Klammern, ohne def und ohne Einrückung. Ohne Klammern passiert nichts.

Klicken Sie sich durch das Programm und beobachten Sie, wie Python bei jedem Aufruf in die Funktion springt und danach zurückkehrt.

Merke

Die Definition muss im Programm vor dem ersten Aufruf stehen. Python liest von oben nach unten und kennt eine Funktion erst, wenn es an ihrem def vorbeigekommen ist.

# Teil 3

Funktionen mit Parametern

Eine Funktion ohne Parameter macht jedes Mal genau dasselbe. Oft soll sie aber etwas leicht Verschiedenes tun: eine Person mit ihrem Namen begrüssen oder eine Linie aus unterschiedlich vielen Zeichen zeichnen. Dafür geben Sie der Funktion beim Aufruf Werte mit.

In der Definition schreiben Sie in die Klammern einen Parameter. Das ist eine Variable, die nur innerhalb der Funktion existiert und als Platzhalter dient. Beim Aufruf schreiben Sie in die Klammern ein Argument, also den konkreten Wert. Python setzt das Argument in den Parameter ein und führt dann die Funktion aus.

def gruss(name):
    print("Hallo", name, "– schön, dass Sie da sind!")

gruss("Mia")
gruss("Ben")
Hallo Mia – schön, dass Sie da sind! Hallo Ben – schön, dass Sie da sind!

Eine Funktion kann auch mehrere Parameter haben, getrennt durch Kommas. Die Argumente werden dann der Reihe nach zugeordnet: das erste Argument zum ersten Parameter, das zweite zum zweiten. Die Reihenfolge ist also wichtig, und die Anzahl muss stimmen.

Parameter gelten nur in der Funktion

Ein Parameter existiert nur, solange die Funktion läuft. Ausserhalb der Funktion kennt Python ihn nicht. print(name) nach dem Aufruf führt deshalb zu einem NameError.

Als Argument dürfen Sie alles verwenden, was einen Wert ergibt: eine Zahl, einen Text, eine Variable oder eine ganze Rechnung wie linie("-", 3 * 4). Python rechnet das Argument zuerst aus und übergibt dann das Ergebnis.

# Teil 4

Stolpersteine

Wird die Funktion aufgerufen, bevor sie definiert ist, meldet Python einen NameError. Fehlt der Doppelpunkt nach den Klammern, gibt es einen SyntaxError, fehlt die Einrückung einen IndentationError.

Bei Parametern ist der häufigste Fehler eine falsche Anzahl Argumente. Ruft man gruss() ohne Argument auf, obwohl die Funktion einen Parameter erwartet, oder gibt man zu viele Argumente mit, meldet Python einen TypeError. Und ein Aufruf ohne Klammern, etwa nur gruss, löst zwar keinen Fehler aus, führt die Funktion aber auch nicht aus. Das Programm tut dann einfach nichts, was die Fehlersuche schwierig macht.

Ausblick

Ihre Funktionen geben bisher mit print() etwas aus. Später lernen Sie return kennen. Damit liefert eine Funktion ein Ergebnis zurück, mit dem das Programm weiterrechnen kann, so wie len() eine Zahl zurückgibt.
