If-Else in Python

Informatik · Python · Kontrollstrukturen

Entscheidungen mit if und else

Bisher liefen Ihre Programme immer gleich ab, Zeile für Zeile. Mit der if-Anweisung kann ein Programm auf Eingaben reagieren und je nach Situation etwas anderes tun.

Teil 1 · Die Idee

Wenn …, dann …, sonst …

Im Alltag treffen Sie ständig solche Entscheidungen: Wenn es regnet, nehme ich einen Schirm mit, sonst nicht. Ein Programm macht dasselbe. Es prüft eine Bedingung. Ist sie erfüllt, wird der eine Teil ausgeführt, sonst der andere. Danach geht es für beide Wege gleich weiter.

Teil 2 · Die if-Anweisung

Aufbau einer if-Anweisung

temperatur = int(input("Temperatur in °C: "))
if temperatur >= 25:
    print("Badewetter!")

Die Zeile mit print wird nur ausgeführt, wenn die Temperatur mindestens 25 °C beträgt. Bei einer tieferen Temperatur passiert nichts.

if
Das Schlüsselwort leitet die Entscheidung ein.
temperatur >= 25
Die Bedingung. Sie ergibt immer True (wahr) oder False (falsch).
:
Der Doppelpunkt schliesst die Kopfzeile ab. Er ist Pflicht.
␣␣␣␣print(…)
Der eingerückte Block (4 Leerzeichen). Er wird nur ausgeführt, wenn die Bedingung True ist.
⚠ Hinweis

input() liefert immer Text, auch wenn Sie eine Zahl eintippen. Mit int(…) wird daraus eine ganze Zahl, mit float(…) eine Dezimalzahl. Erst dann können Sie mit >= rechnen und vergleichen.

Teil 3 · Bedingungen

Vergleichsoperatoren

Eine Bedingung ist meistens ein Vergleich. Python stellt dafür sechs Operatoren zur Verfügung. Das Ergebnis ist immer ein Wahrheitswert: True oder False.

OperatorBedeutungBeispielErgebnis
==gleich7 == 7True
!=ungleich7 != 3True
<kleiner als7 < 3False
>grösser als7 > 3True
<=kleiner oder gleich7 <= 7True
>=grösser oder gleich3 >= 7False
★ Merke

= ist eine Zuweisung: x = 5 speichert 5 in x.
== ist ein Vergleich: x == 5 fragt, ob x gleich 5 ist.

Auch Texte lassen sich vergleichen. Dabei zählt jede Kleinigkeit, auch Gross- und Kleinschreibung:

antwort = input("Hauptstadt der Schweiz? ")
if antwort == "Bern":
    print("Richtig!")

Teil 4 · Zwei Wege

Der Sonst-Fall mit else

Mit else legen Sie fest, was passieren soll, wenn die Bedingung False ist. Es wird also immer genau einer der beiden Blöcke ausgeführt.

temperatur = int(input("Temperatur in °C: "))
if temperatur >= 25:
    print("Badewetter!")
else:
    print("Jacke anziehen")

else hat keine eigene Bedingung, aber ebenfalls einen Doppelpunkt. Es steht auf derselben Einrückungsstufe wie das zugehörige if.

Teil 5 · Mehrere Wege

Weitere Fälle mit elif

Oft gibt es mehr als zwei Möglichkeiten. Dafür gibt es elif, die Kurzform von «else if». Sie können beliebig viele elif-Zweige zwischen if und else einfügen.

temperatur = int(input("Temperatur in °C: "))
if temperatur >= 25:
    print("Badewetter!")
elif temperatur >= 15:
    print("Angenehm, T-Shirt reicht")
else:
    print("Jacke anziehen")

Python prüft die Bedingungen von oben nach unten. Sobald eine Bedingung True ergibt, wird ihr Block ausgeführt. Alle folgenden Zweige werden übersprungen, auch wenn ihre Bedingung ebenfalls zutreffen würde.

★ Merke

In einer if-elif-else-Kette wird genau ein Block ausgeführt: der erste, dessen Bedingung zutrifft, oder sonst der else-Block. Bei 30 °C gibt das Programm oben deshalb nur «Badewetter!» aus, obwohl 30 auch grösser als 15 ist.

Teil 6 · Einrückung

Was gehört zum Block?

Python erkennt an der Einrückung, welche Zeilen zu einem Block gehören. Üblich sind 4 Leerzeichen (in WebTigerPython erzeugt die Tabulatortaste genau das). Ein Block kann beliebig viele Zeilen enthalten.

temperatur = int(input("Temperatur in °C: "))
if temperatur >= 25:
    print("Badewetter!")
    print("Sonnencreme nicht vergessen")
print("Programm fertig")

Die beiden eingerückten Zeilen werden nur bei mindestens 25 °C ausgeführt. Die letzte Zeile ist nicht eingerückt. Sie gehört nicht mehr zur if-Anweisung und wird immer ausgeführt.

Teil 8 · Typische Fehler

Die vier häufigsten Stolpersteine

1. Doppelpunkt vergessen

✗ Falsch

if temperatur >= 25
    print("Badewetter!")

✓ Richtig

if temperatur >= 25:
    print("Badewetter!")

2. Zuweisung = statt Vergleich ==

✗ Falsch

if antwort = "Bern":
    print("Richtig!")

✓ Richtig

if antwort == "Bern":
    print("Richtig!")

3. Einrückung fehlt

✗ Falsch

if temperatur >= 25:
print("Badewetter!")

✓ Richtig

if temperatur >= 25:
    print("Badewetter!")

4. Zahl aus input() nicht umgewandelt

✗ Falsch

alter = input("Alter: ")
if alter >= 18:
    print("volljährig")

✓ Richtig

alter = int(input("Alter: "))
if alter >= 18:
    print("volljährig")

Ü3Auf die Reihenfolge kommt es an

Das Programm soll Schweizer Noten beurteilen. Was wird bei der Note 5.5 ausgegeben? Warum ist das ein Problem und wie korrigieren Sie es?

note = 5.5
if note >= 4:
    print("genügend")
elif note >= 5.5:
    print("sehr gut")
else:
    print("ungenügend")
Lösung anzeigen

Ausgegeben wird «genügend». Die erste Bedingung 5.5 >= 4 ist bereits True, darum werden die restlichen Zweige übersprungen. «sehr gut» kann so nie erscheinen. Die strengere Bedingung muss zuerst geprüft werden:

note = 5.5
if note >= 5.5:
    print("sehr gut")
elif note >= 4:
    print("genügend")
else:
    print("ungenügend")

Teil 10 · Auf einen Blick

Zusammenfassung

if bedingung_1:
    block_a      # nur wenn bedingung_1 True ist
elif bedingung_2:
    block_b      # wenn bedingung_1 False und bedingung_2 True ist
else:
    block_c      # wenn alle Bedingungen False sind
weiter           # wird immer ausgeführt
  • Eine Bedingung ergibt True oder False.
  • Nach jeder Kopfzeile (if, elif, else) steht ein Doppelpunkt.
  • Die Einrückung bestimmt, welche Zeilen zu einem Block gehören.
  • elif und else sind freiwillig. Es wird höchstens ein Block der Kette ausgeführt.
