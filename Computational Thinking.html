# Teil 1

Was ist Computational Thinking?

Computational Thinking heisst nicht, wie ein Computer zu denken. Es heisst, ein Problem so zu durchdenken, dass am Ende eine Lösung steht, die man Schritt für Schritt ausführen kann, von einem Menschen oder von einer Maschine. Der Begriff wurde 2006 von der Informatikerin Jeannette Wing bekannt gemacht. Sie forderte, dass alle diese Denkweise lernen sollten, nicht nur angehende Programmiererinnen und Programmierer.

Dazu gehören vier Werkzeuge. Sie werden selten streng nacheinander eingesetzt, sondern greifen ineinander.

01ZerlegungEin grosses Problem in kleine, lösbare Teilprobleme aufteilen. 02MustererkennungGemeinsamkeiten und Wiederholungen entdecken. 03AbstraktionWichtiges behalten, unwichtige Details weglassen. 04AlgorithmenEine eindeutige Schritt-für-Schritt-Anleitung erstellen.
# Teil 2 · Zerlegung

Zerlegung: das Grosse in Kleines aufteilen

Ein grosses Problem wirkt oft überwältigend. Bei der Zerlegung (englisch decomposition) teilen Sie es in kleinere Teilprobleme auf. Diese zerlegen Sie wieder, bis jedes Stück so klein ist, dass Sie direkt wissen, wie es zu lösen ist. Ein Vorteil: Verschiedene Personen können gleichzeitig an verschiedenen Teilen arbeiten.

Beispiel: Ihre Klasse plant eine Schulreise. Als Ganzes ist das eine unübersichtliche Aufgabe. Zerlegt sieht sie so aus:

  • Schulreise planen
    • Ziel festlegen
      • Ideen sammeln
      • abstimmen
    • Anreise
      • Verbindung suchen
      • Billette für die Gruppe kaufen
    • Programm vor Ort
      • Aktivität buchen
      • Schlechtwetter-Variante
    • Verpflegung
      • Picknick oder Restaurant?
      • Allergien abfragen

In der Programmierung kennen Sie das schon: Mit def schreiben Sie für jedes Teilproblem eine eigene Funktion. Das Hauptprogramm ruft diese Funktionen dann nur noch nacheinander auf.

def noten_einlesen(): ...
def durchschnitt_berechnen(): ...
def zeugnis_ausgeben(): ...

noten_einlesen()
durchschnitt_berechnen()
zeugnis_ausgeben()
# Teil 3 · Mustererkennung

Mustererkennung: Gemeinsamkeiten entdecken

Bei der Mustererkennung suchen Sie nach Dingen, die sich wiederholen oder einander ähneln, innerhalb eines Problems oder zwischen verschiedenen Problemen. Wer ein Muster erkennt, muss eine Lösung nur einmal finden und kann sie danach immer wieder verwenden.

Muster stecken in Zahlenfolgen, aber auch im Alltag: Jedes Rezept für einen Kuchen folgt ungefähr dem gleichen Ablauf. Spamfilter erkennen unerwünschte Mails an typischen Wörtern und Absendern. Ärztinnen erkennen eine Krankheit an einem Muster von Symptomen.

3+47+411+415+4?

Auch im Code lohnt sich der Blick auf Muster. Wenn Sie mehrmals fast dieselben Zeilen schreiben und sich nur ein Wert ändert, ist das ein klares Signal: Hier gehört eine Funktion mit einem Parameter hin.

# Teil 4 · Abstraktion

Abstraktion: das Wesentliche herausschälen

Bei der Abstraktion entscheiden Sie, welche Informationen für Ihr Problem wichtig sind, und lassen alles andere bewusst weg. Was wichtig ist, hängt immer von der Frage ab, die Sie beantworten wollen.

Das bekannteste Beispiel ist der Netzplan von Tram und Bus. Ein Stadtplan zeigt jede Strasse, jede Kurve und die echten Abstände. Wer nur wissen will, wo er umsteigen muss, braucht das alles nicht. Der Netzplan zeigt deshalb nur die Haltestellen, ihre Reihenfolge und die Linien. Er ist ungenau, aber für diesen Zweck viel besser.

Beim Programmieren abstrahieren Sie ständig. Eine Variable note speichert nur die Zahl, nicht das ganze Prüfungsblatt. Und wenn Sie print() aufrufen, müssen Sie nicht wissen, wie der Computer die Buchstaben auf den Bildschirm zeichnet. Eine gute Funktion versteckt ihre Details hinter einem verständlichen Namen.

# Teil 5 · Algorithmen

Algorithmen: eine eindeutige Anleitung

Ein Algorithmus ist eine Schritt-für-Schritt-Anleitung, die ein Problem löst. Damit ein Computer sie ausführen kann, muss sie drei Bedingungen erfüllen: Jeder Schritt ist eindeutig, es gibt also keinen Interpretationsspielraum. Die Schritte haben eine klare Reihenfolge. Und die Anleitung ist nach endlich vielen Schritten fertig.

Menschen verstehen auch ungenaue Anweisungen. Wenn im Rezept «etwas Salz» steht, nehmen Sie eine Prise. Ein Computer dagegen tut genau das, was dasteht, nicht mehr und nicht weniger. Darum ist ein Programm nichts anderes als ein Algorithmus, aufgeschrieben in einer Sprache, die der Computer versteht.

Probieren Sie es aus. Der Roboter versteht genau drei Befehle: vorwaerts() bewegt ihn ein Feld in Blickrichtung, links() und rechts() drehen ihn um eine Vierteldrehung an Ort. Stellen Sie ein Programm zusammen, das ihn auf den Stern bringt, und klicken Sie auf «Ausführen». Weitere Levels finden Sie in den Übungen.

# Teil 6

Alles zusammen: ein Notenrechner

Sie sollen ein Programm schreiben, das für drei Prüfungen den Notendurchschnitt berechnet und meldet, ob er genügend ist. So helfen Ihnen die vier Werkzeuge:

Zerlegung

Das Programm hat drei Teilaufgaben: die Noten bekommen, den Durchschnitt berechnen, das Ergebnis ausgeben und beurteilen.

Muster

Jede Note wird gleich behandelt. Und das Prüfen «genügend oder nicht» kennen Sie schon aus der Lektion über if-else.

Abstraktion

Für die Rechnung zählen nur die drei Zahlenwerte. Fach, Datum und Thema der Prüfungen lassen Sie weg.

Algorithmus

1. Die drei Noten addieren. 2. Die Summe durch 3 teilen. 3. Den Durchschnitt ausgeben. 4. Ist er mindestens 4, «genügend» melden, sonst «ungenügend».

def notenrechner(n1, n2, n3):
    schnitt = (n1 + n2 + n3) / 3
    print("Durchschnitt:", round(schnitt, 2))
    if schnitt >= 4:
        print("genügend")
    else:
        print("ungenügend")

notenrechner(4.5, 5, 3.5)
Durchschnitt: 4.33 genügend
