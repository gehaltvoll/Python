01

Die Idee: repeat vs. while

Mit repeat kennen Sie bereits eine Schleife: Sie sagen dem Programm im Voraus, wie oft etwas wiederholt werden soll. Oft wissen Sie das aber nicht. Denken Sie an eine Passwortabfrage: Sie fragen so lange nach, bis das richtige Passwort kommt – das kann beim ersten oder erst beim zehnten Versuch sein.

Genau dafür gibt es die while-Schleife. Das englische Wort while heisst «solange». Die Schleife wiederholt ihren Körper, solange eine Bedingung wahr (True) ist.

repeat · feste Anzahl 
repeat 3:
    print("Hallo")

«Mach das genau 3-mal.»

while · solange Bedingung wahr 
pw = input("Passwort:")
while pw != "geheim":
    pw = input("Nochmals:")

«Frag so lange, bis es stimmt.»

◆ Merke

Kennen Sie die Anzahl Wiederholungen im Voraus? → repeat.
Hängt das Ende von einer Bedingung ab (Eingabe, Rechenergebnis, Zufall)? → while.

02

Aufbau einer while-Schleife

zahl = 1                 # 1. Startwert festlegen
while zahl <= 4:         # 2. Bedingung prüfen
    print(zahl)          # 3. Schleifenkörper (eingerückt)
    zahl = zahl + 1      # 4. Variable verändern!
print("Fertig")          # 5. geht weiter, sobald Bedingung False
1 2 3 4 Fertig

Ist sie True, läuft der Körper; ist sie False, springt das Programm hinter die Schleife. :Doppelpunkt am Zeilenende – wie bei if und repeat. EinrückungAlle eingerückten Zeilen gehören zum Schleifenkörper. zahl = zahl + 1Etwas im Körper muss die Bedingung irgendwann False machen. Sonst entsteht eine Endlosschleife.

04

Typische Muster

Die meisten while-Schleifen folgen einem von vier Mustern. Wenn Sie diese erkennen, haben Sie für viele Aufgaben schon die halbe Lösung.

① Zählen

Eine Zählvariable startet bei einem Wert und wird in jedem Durchgang verändert.

i = 10
while i >= 0:
    print(i)
    i = i - 2        # 10, 8, 6, 4, 2, 0

② Aufsummieren

Eine Summen-Variable startet vor der Schleife bei 0 und wächst in jedem Durchgang.

summe = 0
i = 1
while i <= 100:
    summe = summe + i
    i = i + 1
print("Summe:", summe)    # 5050

③ Eingabe prüfen

Einmal vor der Schleife fragen – und in der Schleife so lange erneut fragen, bis die Eingabe gültig ist.

alter = input("Ihr Alter:")
while alter < 0 or alter > 120:
    print("Das kann nicht stimmen.")
    alter = input("Ihr Alter:")
print("Danke!")

④ Bis ein Ziel erreicht ist

Man rechnet weiter, bis ein Wert eine Grenze überschreitet, und zählt dabei die Durchgänge.

guthaben = 1000
jahre = 0
while guthaben < 1500:
    guthaben = guthaben * 1.04    # 4 % Zins
    jahre = jahre + 1
print("Nach", jahre, "Jahren")    # Nach 11 Jahren
ℹ Ausblick: break

Mit break verlassen Sie eine Schleife sofort. Man sieht manchmal while True: mit einem break im Innern. Für den Anfang ist es aber übersichtlicher, die Abbruchbedingung direkt nach while zu schreiben.

05

Häufige Fehler

✗ Endlosschleife

Die Variable in der Bedingung wird im Körper nie verändert – die Bedingung bleibt für immer True.

i = 1
while i <= 5:
    print(i)         # i bleibt 1 → läuft endlos

In TigerPython stoppen Sie ein hängendes Programm mit dem Stopp-Knopf.

✗ Falsch eingerückt

Die Änderung der Variable steht ausserhalb der Schleife und wird darum nie im Körper ausgeführt.

i = 1
while i <= 5:
    print(i)
i = i + 1            # gehört nicht zur Schleife!
✗ Eins daneben

< statt <= (oder umgekehrt) führt zu einem Durchgang zu wenig oder zu viel. Prüfen Sie immer den ersten und den letzten Durchgang.

✗ Startwert in der Schleife

Steht summe = 0 im Schleifenkörper, wird die Summe bei jedem Durchgang wieder auf 0 gesetzt.

✗ Schleife läuft nie

Ist die Bedingung schon beim ersten Prüfen False, wird der Körper kein einziges Mal ausgeführt. Das ist manchmal gewollt, oft aber ein Hinweis auf einen falschen Startwert.

✓ Checkliste für jede while-Schleife

1. Hat die Variable in der Bedingung vor der Schleife einen Wert?
2. Wird sie im Körper (eingerückt!) verändert?
3. Wird die Bedingung dadurch irgendwann False?
4. Stimmen erster und letzter Durchgang?
