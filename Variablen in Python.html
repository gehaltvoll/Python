# Teil 1

Was ist eine Variable?

Stellen Sie sich vor, der Computer hat einen riesigen Speicher voller Werte: Zahlen, Wörter, Ja/Nein-Antworten. Damit Sie einen bestimmten Wert später wiederfinden, kleben Sie ihm ein Etikett mit einem Namen an. Genau das ist eine Variable: ein Name, der auf einen Wert zeigt.

In Python erstellen Sie eine Variable mit einem einzigen Gleichheitszeichen. Links steht der Name, rechts der Wert. Diese Zeile nennt man Zuweisung.

punkte = 12
spieler = "Mia"
print(spieler, "hat", punkte, "Punkte")
Mia hat 12 Punkte
punkte12
spieler"Mia"

Wichtig: Das = bedeutet in Python nicht «ist gleich» wie in der Mathematik. Es bedeutet «nimm den Wert rechts und häng das Etikett links daran». Deshalb ist eine Zeile wie punkte = punkte + 1 völlig in Ordnung. Python rechnet zuerst die rechte Seite aus und hängt danach das Etikett an das Ergebnis.

Regeln für Namen

Ein Variablenname besteht aus Buchstaben, Ziffern und dem Unterstrich _, darf aber nicht mit einer Ziffer beginnen. Leerzeichen und Umlaute vermeiden Sie besser: Schreiben Sie anzahl_aepfel statt Anzahl Äpfel. Gross- und Kleinschreibung zählt, Alter und alter sind zwei verschiedene Variablen. Wählen Sie Namen, die verraten, was drinsteht: preis ist besser als x.

# Teil 3

Die vier Grundtypen

Jeder Wert in Python hat einen Typ. Der Typ bestimmt, was Sie mit dem Wert machen können: Mit Zahlen können Sie rechnen, Text können Sie aneinanderhängen. Den Typ müssen Sie nicht angeben. Python erkennt ihn an der Schreibweise des Werts. Mit type() können Sie jederzeit nachfragen.

int

Ganze Zahlen

integer

Ein int ist eine Zahl ohne Komma, also zum Beispiel ein Alter, eine Anzahl Leben im Spiel oder ein Jahrgang. Ganze Zahlen dürfen auch negativ sein und beliebig gross werden. Sie erkennen einen int daran, dass er nur aus Ziffern besteht, ohne Punkt und ohne Anführungszeichen.

leben = 3
jahrgang = 2010
temperatur = -4
print(type(jahrgang))
<class 'int'>
float

Kommazahlen

floating point

Ein float ist eine Zahl mit Nachkommastellen, etwa eine Körpergrösse, ein Preis oder eine Temperatur. In Python schreiben Sie das Komma als Punkt: 1.75, nicht 1,75. Sobald ein Punkt in der Zahl steht, ist sie ein float, auch wenn danach nur eine Null kommt.

groesse = 1.75
preis = 4.0
print(type(preis))
<class 'float'>
Gut zu wissen

Computer speichern Kommazahlen nur annähernd genau. Darum liefert 0.1 + 0.2 den Wert 0.30000000000000004. Das ist kein Fehler von Ihnen, sondern eine Eigenheit aller Programmiersprachen.

str

Text

string, Zeichenkette

Ein str ist Text, also eine Folge von Zeichen. Sie erkennen ihn an den Anführungszeichen, die einfach '…' oder doppelt "…" sein dürfen. Alles zwischen den Anführungszeichen gilt als Text, auch Ziffern: "42" ist keine Zahl, sondern die zwei Zeichen 4 und 2.

vorname = "Lea"
plz = "8180"          # Postleitzahl: Text, denn damit rechnet niemand
print(type(plz))
<class 'str'>
bool

Wahrheitswerte

boolean

Ein bool kennt nur zwei Werte: True (wahr) und False (falsch). Sie werden immer mit grossem Anfangsbuchstaben und ohne Anführungszeichen geschrieben. Wahrheitswerte entstehen meistens durch Vergleiche. Später brauchen Sie sie für Entscheidungen mit if, zum Beispiel: Ist das Spiel vorbei? Hat die Person bezahlt?

alter = 16
volljaehrig = alter >= 18
spiel_vorbei = False
print(volljaehrig)
print(type(spiel_vorbei))
False <class 'bool'>
# Teil 4

Operationen: was Sie mit jedem Typ machen können

Eine Operation verarbeitet einen oder mehrere Werte zu einem neuen Wert. Welche Operationen erlaubt sind und was dabei herauskommt, hängt vom Typ ab. Das Zeichen + zum Beispiel addiert zwei Zahlen, hängt aber zwei Texte aneinander. Die Tabellen zeigen die wichtigsten Operationen für jeden der vier Typen.

Spannend wird es, wenn Sie Typen mischen. Rechnen Sie mit einem int und einem float, wird das Ergebnis ein float: 3 + 0.5 ergibt 3.5. Die Division mit / liefert sogar immer einen float, auch wenn sie aufgeht. Text und Zahl lassen sich dagegen nicht mit + verbinden, Python meldet dann einen TypeError. Eine Ausnahme ist *: Text mal ganze Zahl wiederholt den Text.

Kuriosität

Für Python ist True eigentlich die Zahl 1 und False die Zahl 0. Deshalb ergibt True + True den Wert 2. Im Alltag sollten Sie damit nicht rechnen, aber es erklärt einige überraschende Ergebnisse.

Operationen-Labor

Probieren Sie es aus: Wählen Sie zwei Werte und einen Operator. Das Labor zeigt, was Python ausgeben würde und welchen Typ das Ergebnis hat.

# Teil 5

Typen umwandeln

Manchmal haben Sie einen Wert im falschen Typ. Das passiert vor allem mit input(): Was die Benutzerin oder der Benutzer eintippt, kommt immer als Text an, auch bei einer Zahl. Um damit zu rechnen, wandeln Sie den Text mit int() oder float() in eine Zahl um. Umgekehrt macht str() aus einer Zahl Text, damit Sie sie mit + in einen Satz einbauen können.

eingabe = input("Wie alt sind Sie? ")   # z. B. 15, aber als Text "15"
alter = int(eingabe)                   # jetzt die Zahl 15
naechstes_jahr = alter + 1
print("Nächstes Jahr sind Sie " + str(naechstes_jahr))
Wie alt sind Sie? 15 Nächstes Jahr sind Sie 16
Merke

Rechnen geht nur mit int und float. Wandeln Sie Text vorher um, sonst meldet Python einen TypeError.
