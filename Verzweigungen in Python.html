# Teil 1

Bedingungen: Fragen, die mit Ja oder Nein beantwortet werden

Jede Entscheidung beginnt mit einer Bedingung. Das ist ein Ausdruck, den Python zu True oder False auswertet, also zu einem Wert vom Typ bool. Meistens entsteht eine Bedingung durch einen Vergleich: Ist die Temperatur unter null? Ist das Passwort richtig? Hat der Spieler mehr als 100 Punkte?

Achtung

Ein einzelnes = ist eine Zuweisung: Es hängt ein Etikett an einen Wert. Für den Vergleich «ist gleich?» brauchen Sie immer das doppelte ==.

# Teil 2

Die if-Anweisung: etwas nur manchmal tun

Mit if (englisch für «falls» oder «wenn») führen Sie Code nur dann aus, wenn eine Bedingung erfüllt ist. Ist die Bedingung False, überspringt Python den eingerückten Block einfach und macht danach normal weiter.

if bedingung:
    anweisung_1
    anweisung_2
weiter_im_programm

Das Schlüsselwort if, danach die Bedingung und am Schluss ein Doppelpunkt.

Alles, was nur bei True passieren soll, wird eingerückt, üblicherweise um vier Leerzeichen. TigerPython rückt nach dem Doppelpunkt automatisch ein.

Die erste Zeile, die wieder ganz links beginnt, gehört nicht mehr zum if. Sie wird immer ausgeführt.

# Teil 3

if-else: entweder das eine oder das andere

Oft wollen Sie nicht nur etwas tun, wenn die Bedingung stimmt, sondern auch etwas anderes, wenn sie nicht stimmt. Dafür ergänzen Sie den if-Block mit else («sonst»). Python wählt dann genau einen der beiden Blöcke: den if-Block bei True, den else-Block bei False. Beide zusammen werden nie ausgeführt, und keiner von beiden auslassen geht auch nicht.

Das else steht auf derselben Höhe wie das if, hat keine eigene Bedingung und endet ebenfalls mit einem Doppelpunkt.

Merke

else braucht keine Bedingung, denn es fängt automatisch alle Fälle auf, in denen die if-Bedingung False ist. Schreiben Sie also nie else alter < 18:.

# Teil 4

if-elif-else: mehr als zwei Möglichkeiten

Manche Entscheidungen haben mehr als zwei Ausgänge, zum Beispiel eine Schulnote, ein Ticketpreis nach Alter oder eine Wetterwarnung in mehreren Stufen. Dafür gibt es elif, die Kurzform von «else if», also «sonst, falls».

Python prüft die Bedingungen von oben nach unten. Bei der ersten, die True ist, führt es deren Block aus und überspringt den ganzen Rest. Die weiteren Bedingungen werden gar nicht mehr geprüft. Ist keine Bedingung erfüllt, kommt der else-Block zum Zug. Sie dürfen beliebig viele elif-Teile schreiben, das else am Schluss ist freiwillig.

Im Beispiel wird eine Schweizer Schulnote in Worte übersetzt. Achten Sie darauf, welche Bedingungen bei einer Note von 6 überhaupt geprüft werden.

Warum die Reihenfolge zählt

Weil Python bei der ersten erfüllten Bedingung aufhört, müssen Sie die strengste Bedingung zuerst prüfen. Stünde note >= 4 zuoberst, würde auch eine 6 nur als «genügend» gelten, denn 6 ist ja ebenfalls grösser als 4.

# Teil 5

Stolpersteine

Die meisten Fehler bei Verzweigungen sind kleine Tippfehler. Fehlt der Doppelpunkt am Ende der if-Zeile oder steht ein = statt ==, meldet Python einen SyntaxError. Fehlt die Einrückung, erscheint ein IndentationError. Diese Fehler sind lästig, aber harmlos, weil Python Sie sofort darauf hinweist.

Heimtückischer sind Logikfehler: Das Programm läuft, liefert aber ein falsches Ergebnis. Ein typisches Beispiel ist der Unterschied zwischen mehreren einzelnen if und einer Kette mit elif. Einzelne if-Anweisungen werden alle unabhängig voneinander geprüft, bei elif gewinnt nur die erste passende Bedingung.

Wenn sich die Fälle gegenseitig ausschliessen sollen, ist die elif-Kette die richtige Wahl.
